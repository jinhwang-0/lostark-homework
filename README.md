## 이번 마무리 반영사항
- 레이드 카테고리 영역을 별도 상자 안에 배치하고 은은한 음영 추가
- 캐릭터 카드 정보 순서 변경: 아이템레벨 / 직업 → 전투력 / 닉네임
- 레이드 카테고리 카드를 드래그해서 순서 변경 가능
- 길드원/캐릭터 탭: 사용자 4개씩 한 줄, 사용자 내부 캐릭터 2개씩 한 줄 배열
- 기존 기능 유지: 우측 가능 길드원 드래그 배치, 파티 바로가기, 최근 접속 기억, 자동 주간 초기화
